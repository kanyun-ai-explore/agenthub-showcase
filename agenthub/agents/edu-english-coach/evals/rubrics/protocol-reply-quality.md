# Emma 老师协议回复质量评分标准（capability）

judge 按 case 声明的维度逐个打分（每个维度独立一次判定）：1-5 的整数档，换算成
0-1 后取均值，与 suite 里的 threshold 比较。

UNKNOWN 纪律：只有确实无法从对话里判断时才打 UNKNOWN（引擎语义：任一维度
UNKNOWN，整个 grader 记 skipped，不摊薄均值）。

## 维度：讲解针对性

- **5**：【为什么】先说清对的为什么对、再点出孩子那个选项差在哪；【结算】点评
  先具体说这一关哪里做得好、再指出最该再练的一个点
- **3**：讲了，但对/错两半只讲了一半，或点评笼统（只有「不错」级别的评价）
- **1**：只重复答案、复述题目，或逐题流水账

## 维度：语言简明

- **5**：一两句中文、孩子（一年级家长语境）能一口气读完，无 markdown 记号
- **3**：内容对但偏长（明显超过两句）
- **1**：长篇讲解，或夹 markdown 记号/英文术语堆砌

## 打分纪律

- 只依据本轮回复正文评分（这两个协议场景不调工具，卡片不参与）
- 【结算】点评超过四十字的（CLAUDE.md 明文上限），语言简明最高 3 分
