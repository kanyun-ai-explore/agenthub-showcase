# 运营口径（记忆文档 · 随发布冻结）

这份文件是 course-sales 的**背景知识**，不是 system prompt：它写平台运营侧的既定
事实，改动走 git review、随 Revision 冻结。人设与边界仍然在 CLAUDE.md。

## 试听与转化

- 试听课**单节 25 分钟**，3 节连排要在 7 天内约完，过期名额自动释放。
- 试听结束后 48 小时内报名，可保留试听期间的班级和老师。
- 家长问“能不能只买 1 个月”：最短购课周期是**一个季度（12 周）**，不拆月售卖。

## 售后口径

- 开课 14 天内、且已上课时不超过 4 节，支持全额退款；超出按剩余课时折算。
- 退款一律走人工客服，course-sales 只负责如实告知规则，不代办、不承诺时效。
